# แผนทดสอบ Bangchak Oil Price

เอกสารนี้ใช้ทดสอบระบบก่อนพึ่งพาจริง แบ่งเป็น 3 ส่วน

- **SIT** ทดสอบการทำงานของแต่ละชิ้นและการเชื่อมต่อระหว่างกัน (สคริปต์ดึงราคา, workflow, Apps Script, หน้าเว็บ)
- **UAT** ทดสอบจากมุมผู้ใช้จริงว่าทำงานตามที่ต้องการ
- **ISS** จำลองกรณีที่ราคาเปลี่ยนและกรณีดึงข้อมูลล้มเหลว เพื่อทดสอบการเปิด GitHub Issue

สถานะ: `ยังไม่ทำ` / `ผ่าน` / `ไม่ผ่าน` / `ข้าม`

---

## 0. สภาพแวดล้อมและข้อมูลทดสอบ

| รายการ | ค่า |
| --- | --- |
| รีโป | `maoz158/bangchak-oil-price` (public) |
| หน้าเว็บจริง | https://maoz158.github.io/bangchak-oil-price/ |
| Apps Script endpoint | Web app ของ "Fuel Log API" (Execute as Me, Anyone) |
| Google Sheet | "Fuel Log" แท็บ `Fills` |
| Branch สำหรับทดสอบ | `dev` (แยกจาก `main` ไม่กระทบหน้าเว็บจริง) |

กฎสำคัญ
- ห้ามทดสอบ Issue หรือ workflow บน `main` ก่อน ให้ทำบน `dev` เท่านั้น
- แถวทดสอบที่เขียนลง Sheet ต้องลบออกหลังทดสอบ และตรวจว่า `GET` คืน `rows: []`
- Issue ทดสอบต้องปิดหลังตรวจเสร็จ ชื่อ Issue ที่ workflow สร้างไม่มีคำว่า TEST จึงต้องบันทึกหมายเลข Issue ที่สร้างในระหว่างทดสอบ แล้วปิดเฉพาะใบนั้น

## 1. Simulation สำหรับ Issue

### ISS-A: จำลองในเครื่อง (ไม่แตะ GitHub)

ใช้สคริปต์ harness ที่ import `scripts/fetch_prices.py` แล้วแทนที่ `fetch_raw` ด้วย payload ปลอม ทำงานบนสำเนาของรีโปเพื่อไม่กระทบ `data/` จริง

ขั้นตอน
1. คัดลอกรีโปไปโฟลเดอร์ชั่วคราว
2. สร้าง payload ปลอมจาก `data/latest.json` โดยเปลี่ยน `PriceToday` ของ G95 เป็นค่าอื่น (เช่น +0.50)
3. รันโดยกำหนด `ISSUE_BODY_FILE` และ `GITHUB_OUTPUT` ไปไฟล์ชั่วคราว
4. ตรวจผลลัพธ์ตามเกณฑ์ด้านล่าง

| ID | กรณี | ผลที่คาดหวัง |
| --- | --- | --- |
| ISS-A1 | ราคา G95 เปลี่ยน | `price_changed=true`, `latest.json` เปลี่ยน, `history.json` ต่อท้าย 1 แถว, ไฟล์ issue body มีราคาเก่าและใหม่ และส่วนต่างถูกต้อง |
| ISS-A2 | ราคา E20 เปลี่ยน อย่างเดียว | เหมือน ISS-A1 แต่เป็น E20 |
| ISS-A3 | เฉพาะ `PriceTomorrow` หรือ `PriceYesterday` เปลี่ยน | `displayed_changed=true` (เขียน `latest.json`) แต่ `price_changed=false` และ `history.json` ไม่เปลี่ยน |
| ISS-A4 | ไม่มีอะไรเปลี่ยน | ไม่เขียนไฟล์ใด ๆ `price_changed=false` ไม่มี issue body |
| ISS-A5 | มีการเปลี่ยนแค่ `OilPriceTime` | `displayed_changed=true` แต่ `price_changed=false` |
| ISS-A6 | รันครั้งแรกไม่มี `latest.json` | `price_changed=false` (ไม่แจ้งเตือนครั้งแรก) และไฟล์ถูกสร้าง |
| ISS-A7 | `latest.json` เสีย (JSON ผิด) | ไม่ crash, ถือว่าไม่มีข้อมูลก่อนหน้า และไม่ส่ง issue ผิด |

### ISS-B: End-to-end บน GitHub (branch `dev`)

ไม่ต้องแก้โค้ด ใช้การแก้ข้อมูลบน `dev` แทน

ขั้นตอน
1. สร้าง branch `dev` จาก `main`
2. บน `dev` แก้ `data/latest.json` ให้ `PriceToday` ของ G95 ต่างจากราคาจริงเล็กน้อย (ราคาจริงดูได้จากเว็บ Bangchak หรือจาก log ของ run ล่าสุด) แล้ว commit ไว้เฉพาะบน `dev`
3. รัน `gh workflow run update-prices.yml --ref dev`
4. ดูผลจาก `gh run watch`

| ID | กรณี | ผลที่คาดหวัง |
| --- | --- | --- |
| ISS-B1 | ราคาต่างจากข้อมูลบน `dev` | Run เป็นสีเขียว, มี commit ใหม่บน `dev` ที่ `data/` เท่านั้น, มี Issue ชื่อ `ราคาน้ำมันเปลี่ยน <วันที่>`, เนื้อหาถูกต้อง |
| ISS-B2 | รันซ้ำทันทีหลัง ISS-B1 (ราคาไม่เปลี่ยน) | ไม่มี commit ใหม่และไม่มี Issue ใหม่ |
| ISS-B3 | ตรวจ Issue body | ลิงก์หน้าเว็บถูกต้อง ตัวเลขตรงกับ `data/latest.json` |

### ISS-C: จำลองการดึงข้อมูลล้มเหลว (branch `dev`)

ขั้นตอน: บน `dev` เปลี่ยน `API_URL` ใน `scripts/fetch_prices.py` เป็นโดเมนที่ใช้ไม่ได้ (เช่น `https://example.invalid/api`) แล้วรัน workflow

| ID | กรณี | ผลที่คาดหวัง |
| --- | --- | --- |
| ISS-C1 | API ใช้ไม่ได้ | Run ล้มเหลว, มี Issue ชื่อ `ดึงราคาน้ำมันไม่สำเร็จ <วันที่>` พร้อมลิงก์ไปที่ run |
| ISS-C2 | Issue ลิงก์ไป run ที่ถูกต้อง | เปิดแล้วเห็น log ที่มี `fetch failed:` |
| ISS-C3 | ดึงข้อมูลได้แต่โครงสร้างผิด (ไม่มี OilList) | Run ล้มเหลวและมี Issue ล้มเหลวเหมือน ISS-C1 |

หลังทดสอบ ISS-B และ ISS-C
- ปิด Issue ทดสอบทุกใบ
- ลบ branch `dev` (`git push origin --delete dev`) หลังยืนยันกับคุณแล้ว

## 2. SIT: การทำงานของชิ้นส่วนต่าง ๆ

### SIT-1 สคริปต์ดึงราคา
